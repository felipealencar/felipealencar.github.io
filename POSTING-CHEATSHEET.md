# Homepage Posting Cheat Sheet

Use these labels when you publish a post if you want it to appear on the homepage.

## Recent News

- Add the label `en`
- Add one of these labels: `research` or `work`
- The homepage shows up to 3 of these posts in `Recent News`

## Featured Projects And Papers

- Add the label `featured`
- Add a representative image to the post
- The homepage shows up to 4 featured posts here
- The card uses only the post title and image

## Latest Posts

- Add the label `en`
- This section currently lists the latest English posts from the blog
- The homepage shows up to 12 posts here

## Image Tip

- Prefer setting a clear first image near the top of the post
- If Blogger has a post thumbnail, the homepage uses it
- Otherwise, the homepage falls back to the first image found in the post body
